FOOD COST LAB v2 — Android導入手順

改良内容:
- 仕入れ品を登録すると商品原価計算で選択可能
- 1商品に複数の材料を追加し、使用量から合計原価を自動計算
- 仕入れ品価格の変更は、保存済みレシピの表示原価にも反映
- localStorageによる自動保存、JSONバックアップと復元
- Android向けレイアウト、PWA・オフラインキャッシュ対応

インストール:
1. ZIPを展開。
2. GitHubでPublicリポジトリ（例 food-cost-lab）を作成。
3. index.html、manifest.json、sw.js、icon-192.png、icon-512.png をリポジトリ直下にアップロードしてコミット。
4. Settings → Pages → Deploy from a branch → main / (root) → Save。
5. 公開されたHTTPS URLをAndroidのChromeで開く。
6. Chromeの︙から「アプリをインストール」または「ホーム画面に追加」。

データ:
- 商品・仕入れ品・施策は同じ端末・同じブラウザ内に自動保存されます。
- ブラウザのデータ消去や端末変更で失われる場合があるため、定期的にバックアップしてください。
- クラウド同期・ログイン機能はありません。
- 仕入れ品の価格変更は保存済み商品の表示原価にも反映されます。過去時点の価格履歴は保持しません。
- Publicリポジトリではアプリのコードは公開されます。入力データは通常ブラウザ内に保存され、GitHubに送信されません。
